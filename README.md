# strftime-lite

自写时间格式串引擎（格式化与解析），只用 Go 标准库。

```
go test ./...
go run ./cmd/strftime-lite --layout "%Y-%m-%d %H:%M:%S"
go run ./cmd/strftime-lite --layout "100%% done at %H:%M"
```

## 口径（README 为准）

- **数字字段要补零**：`%m`、`%d`、`%H`、`%M`、`%S` 都是两位（不足补 0）。
  `--layout "%Y-%m-%d %H:%M:%S"` 在 1770000000 秒（UTC 2026-02-02 02:40:00）按口径是
  `2026-02-02 02:40:00`，现在给 `2026-2-2 2:40:0`。
- **`%%` 表示一个字面百分号**：`100%% done` 按口径是 `100% done`，现在给 `100%% done`。
- 支持 `%Y %m %d %H %M %S %%`，未知指令要报错并指出位置；末尾孤立的 `%` 原样输出。
- 解析方向：`--parse "2026-02-02 02:40:00" --layout "%Y-%m-%d %H:%M:%S"` 要给出对应的 unix 秒；
  不匹配要报错并给出位置。
- 不变量：`Parse(Format(t, layout), layout) == t`（对秒级精度成立）；`Format` 对普通文本原样输出；
  同一输入重复格式化结果相同。
- 规模：10 万次格式化线性完成，不许用会回溯的正则。

## 现在的行为

- 数字字段补零：`2026-02-02 02:40:00`；`%Y` 四位。
- `%%` 还原为一个百分号；末尾孤立的 `%` 原样输出。
- 未知指令报错并指出位置；`--parse` 按格式串解析出 unix 秒，
  不匹配、多余字符、非法数字、字段越界都报错并给位置。

## 计划新增的能力

```
--layout 格式串
--at unix 秒
```

## 输出

```
2026-02-02 02:40:00
```
